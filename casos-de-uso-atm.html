5
Desencadenar:El cliente solicita revisar su saldo
6
Precondiciones:Pre-1: El usuario ha completado con éxito la identificación
Pre-2: El cajero automático funciona correctamente
7

8
Flujo normal:1. El cliente selecciona la opción "Revisar saldo" en el menú principal del cajero automático.
2. El sistema envía una solicitud al servidr del banco para consultar los saldos de las cuentas vinculadas
3. El servidor procesa la consulta y devuelve los saldos disponibles y totales
4. El sistema muestra en pantalla los saldos de la cuenta del cliente
5. El sistema ofrece la opción de imprimir un comprobante o regresar al menú pricipal
9
Flujo alternativo:1.1 Selección de cuenta específica (si aplica): Si el cliente tiene múltiples cuentas, el sistema muestra una lista y el cliente selecciona una.

35
Actor primarioClienteActores Secundarios: Sistema de cajero automatico
36
Descripción:El usuario realiza con éxito su identificación en la terminal al insertar su tarjeta y digitar correctamente su NIP. La plataforma corrobora dichos datos para darle acceso a su cuenta
37
Desencadenar:El cliente se identifica como usuario
38
Precondiciones:Pre-1: El cliente cuenta con una cuenta y una tarjeta activas
Pre-2: La terminal se encuentra en servicio operativo
Pre-3: El usuario se encuentra físicamente con el cajero
39
Postcondición:Pos-1: La identidad del usuario es verificada por la institución
Pos-2: El panel con las opciones queda visible para el cliente
40
Flujo normal:1. El usuario introduce su tarjeta en la terminal
2. La plataforma lee y procesa los datos de la tarjeta
3. El sistema solicita al usuario su NIP
4. El cliente digita su NIP con el teclado numérico y pulsa confirmar
5. El sistema corrobora el NIP con los registros y valida la situación
6. El sistema reconoce legítimamente al usuario y le brinda acceso
41
Flujo alternativo:3.1 Interrupción del procedimiento: El cliente decide presionar la opción "Cancelar" a medio proceso, anulando la operación. La terminal expulsa la tarjeta de su ranura y regresa al panel inicial
42
Excepciones:3.2 Tarjeta o plástico ilegible o dañado: La tarjeta al ser ingresada en la terminal está con defectos físicos o daños que impiden su lectura, la máquina da error y devuelve la tarjeta al usuario
43
Prioridad:Alta
44
Frecuencia de usos:Alta
45
Reglas comerciales:
46
Otra información:La contraseña jamás debe mostrarse con caracteres legibles
47
Supuestos:Se asume que el lector de tarjetas y el teclado físico del cajero operan debidamente sin alteraciones ni afectaciones

Actor primarioClienteActores secundarios:Sistema de cajero automatico
52
Descripción:El cliente realiza el pago de servicios o tarjetas de crédito (incluyendo extensión a Visa y MasterCard) desde su cuenta
53
Desencadenar:El cliente selecciona la opción "Realizar pagos" en el menú principal
54
Condiciones previas:Pre-1: El usuario ha iniciado sesión correctamente
Pre-2: La cuenta tiene fondos suficientes o línea de crédito disponible
55
Postcondición:Pos-1: El pago se registra y aplica exitosamente en el sistema del proveedor
Pos-2. Se emite un comprobante de pago impreso para el cliente
56
Flujo normal:1. El cliente selecciona la opción "Realizar pagos" en el menú principal.
2. El sistema muestra las categorías de pago disponibles (Servicios, Tarjetas de Crédito)
3. El cliente selecciona el tipo de servicio o tarjeta a pagar (incluye opciones de pago con tarjeta Visa o Mastercard).
4. El cliente ingresa o escanea los datos requeridos
5. El sistema valida los datos y solicita confirmación.
6. El cliente confirma la operación.
7. El sistema procesa la transacción y cobra los fondos.
8. El sistema muestra éxito, imprime comprobante y regresa al menútd
57
Flujo alternativo:3.1 Pago de Tarjeta de Crédito (Visa o Mastercard): El cliente selecciona la franquicia (visa o Mastercard), ingresa el número de tarjeta y el monto a pagar
58
Excepciones:E-1. Fondos insuficientes: El sistema muestra error por saldo insuficiente y ofrece reintentar o regresar al menú
59
Prioridad:Alta
60
Frecuencia de usos:Alta
61
Reglas comerciales:
62
Otra información:Las transacciones de pago con tarjeta de crédito de terceros requieren validación con la red que le corresponda
63
